## Description (proposed)

Favor Printer connects a supported USB Zebra label printer to Favor RSVP, so authorized campus teams can print labels requested by check-in staff. Enroll the printer host with a one-time code from RSVP printing administration, connect the Zebra and keep the app open while labels are needed.

Check-in, attendee lookup and attendance changes stay in the **Favor RSVP website on another device**. Favor Printer does not create or edit attendance records. Printer and host identity, assignments and cloud print jobs are controlled by RSVP.

This is a dedicated **foreground printer host**: printing pauses when the iPad is locked, the app goes into the background or the printer/network disconnects. The cloud queue can wait; the Mac printer host remains available as fallback.
