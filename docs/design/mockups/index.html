Set up Favor Printer

This app lets your Zebra label printer print check-in labels from Favor RSVP. Setup takes about two minutes.

  1. Pick your printer
  2. Enter the code from an admin
  3. Print a test label

Step 1 of 5

Add the printer in System Settings

macOS did not let Favor Printer set this up. You can add it yourself:

  1. Open System Settings, then Printers & Scanners.
  2. Click Add Printer, and choose the Zebra from the list.
  3. Come back here and choose Check again.

Replace the old print relay

An older print relay is still running on this Mac. If both ran, they could claim the same labels, so Favor Printer stays off until the old one is turned off.

Nothing is deleted, and no password or code is copied from the old relay.

Favor Printer

Turn off the old print relay?

Favor Printer will stop the old relay now and keep it from starting when you log in. Labels printed by the old relay stop until you finish setting up here.

Favor Printer checks that the old relay is gone before it starts printing.
