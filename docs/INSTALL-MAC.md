# Install Favor Printer on a Mac

## Download

Download from the latest release page: https://github.com/favorchurch/favor-printer/releases/latest

Volunteer instructions are also at https://rsvp.favor.church/printer.

## Pick the right DMG

The DMG file name ends with the chip type:

| Mac | File to download |
| --- | --- |
| Apple silicon (M1, M2, M3 or later) | `Favor-Printer-<version>-arm64.dmg` |
| Intel | `Favor-Printer-<version>-x64.dmg` |

Not sure which you have? Apple menu > **About This Mac**. **Chip** says Apple M-something for Apple
silicon. **Processor** says Intel for an Intel Mac.

## Install

1. Open the DMG and drag **Favor Printer** into Applications.
2. Open Favor Printer from Applications.
3. Follow the setup window. An admin gives you a six-digit code from **Set up printing** in Favor RSVP.

The app lives in the menu bar. If you cannot see its icon, it may be hidden behind the notch. See
[TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Check the installed version

Reopen Favor Printer from Applications to open its status window. The line near the bottom reads
**Version x.y.z**, followed by **(Stable)** or **(Preview)**. Compare it with the latest release page
to see whether you are current.
